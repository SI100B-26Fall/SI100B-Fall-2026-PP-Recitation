## 机制之间的联系

Coordinate 的 self 始终接收本次操作的实例。NamedCoordinate 使用同一个实例复用基类初始化与方法；super 是查找代理，不额外创建父对象。PointGroup 通过组合保存坐标，Path 再继承 PointGroup 并加入容器协议。

普通实例数据、类属性与 property 不能使用同一条简化规则解释。前面的查找例子只针对普通属性，后面的 property 是数据描述符。ABCMeta 是 type 的子类，因此“本例类的精确类型为 type”不能推广成对全部类的绝对断言。

NotImplemented 是运算协议的返回值，NotImplementedError 是异常。__eq__ 与 __hash__ 有配合要求，不能对可变坐标随意补一个基于当前字段值的哈希。frozen 限制通常字段赋值，不承诺深度不可变或安全隔离。
